# Fishstrap Roblox FPS Unlocker

**Fishstrap Roblox FPS Unlocker** is a **fishstrap roblox** bootstrapper: FPS unlock, **fast flags** / **fflags**, **bloxstrap fast flags** presets, **multi instance**, shaders and custom fonts. A **bloxstrap** alternative next to **voidstrap** — **fishstrap github** is not an executor.

## Getting Started
1. Download v3.0.2.
2. Run `Fishstrap.exe` as Administrator.
3. Set target FPS.
4. Pick a fast flags preset.
5. Launch Roblox.

Fishstrap does not run scripts. It only unlocks FPS, applies client flags and visuals.


## FAQ

**Safe?**
Open source. No gameplay injection.

**Vs Bloxstrap / Voidstrap?**
Fishstrap adds multi instance, shader presets, fonts and Discord RPC. Voidstrap stays minimal.

**After a Roblox update?**
Run as Administrator, re-apply flags. Signatures refresh hourly.

## Requirements
Windows 10/11 (64-bit) · Roblox installed · 144Hz+ monitor recommended
